## 🚀 Featured Projects

### 🔌 usbfix — A safer macOS CLI for USB drives
A terminal-friendly alternative to Disk Utility for inspecting, verifying, repairing, wiping, and formatting USB drives using native macOS utilities (`diskutil`, `fsck`).
- Safety layers: no dangerous defaults, internal-disk lock, explicit whole-disk scoping, textual confirmation (`ERASE diskN`), `--dry-run` everywhere
- Ships its own **agent skill (`usbfix-cli`)** so AI assistants can use it correctly

```bash
brew install santgabo/tap/usbfix
```

🔗 **[santgabo/USBfixertool-CLI](https://github.com/santgabo/USBfixertool-CLI)**

---

### 🍐 PearBooks — Export Apple Books EPUBs on macOS
Apple Books can store an EPUB as a folder with an `.epub` extension. This tool repackages it as a standard EPUB ZIP, with `mimetype` first and uncompressed — and also handles EPUBs that are already ZIPs.

- Never deletes or modifies originals; preserves all internal files
- Per-resource **SHA-256** verification, atomic publish, per-run JSON report
- Validated with official **EPUBCheck**

```bash
./"Formateador de libros.sh" "$HOME/Library/Mobile Documents/iCloud~com~apple~iBooks/Documents"
```

🔗 **[santgabo/PearBooks](https://github.com/santgabo/PearBooks)** · `Python` · `Shell`

### 🪟 windows-skills — Windows-focused Claude skills
Claude skills for **Windows**, each with reference docs, ready-to-use automation scripts, and **evals** to check whether the skill actually improves answers.

- Includes **`kopia-windows`**: operate Kopia CLI on Windows (S3, B2, Azure, rclone, SFTP repos, snapshots, point-in-time restores, retention, scheduled backups)
- Standard `skills.sh` layout, installable without cloning:

```bash
npx skills add santgabo/windows-skills --skill kopia-windows -a claude-code
```

🔗 **[santgabo/windows-skills](https://github.com/santgabo/windows-skills)**
